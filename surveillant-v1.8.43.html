Surveillant

Surveillant est un programme permettant de recuperer un ou plusieurs flux video.

Utilisation rapide

  • Au premier lancement, suivez le tutoriel pour préparer une ESP32-CAM puis renseigner son IP.
  • Ouvrez Menu pour renseigner les IP et les libellés des caméras.
  • Le champ Chemin du flux vaut généralement /stream.
  • Le réglage Fréquence de maj active un rafraîchissement automatique décalé des flux.
  • Le réglage Décalage maj définit le temps d'attente entre deux caméras : de 1,2 seconde à 1 minute.
  • Le réglage Date en haut permet de garder une date numérique ou d'afficher le jour et le mois en toutes lettres.
  • Le sélecteur violet d'agencement choisit le nombre de flux par ligne, de Auto à 8.
  • 💡 bascule la LED d'une caméra ; le bouton ampoule du haut agit sur toutes les LED.
  • ▣ capture ou enregistre une image PNG via le chemin de capture configuré.
  • ↻ recharge un flux, ⤾ tourne l'image, ⇄ active le miroir, ⛶ agrandit la caméra.
  • Les boutons de chaque caméra sont placés sur les côtés du flux pour laisser plus de place à l'image.
  • Cliquez sur le logo pour activer le mode Surveillance : la barre du haut reste en place et seuls les flux restent visibles sous celle-ci. Cliquez de nouveau sur le logo pour revenir à l'affichage normal.
  • Si une caméra est indisponible, l'icône Surveillant remplace le flux dans sa case.
  • L'horodatage du haut sert aussi aux messages et aux noms de fichiers de capture.

Pour les geeks

Langages utilisés

La page est autonome et repose sur trois langages standards du navigateur : HTML pour la structure, CSS pour l'affichage et les thèmes, et JavaScript pour créer les cartes caméra, envoyer les commandes et sauvegarder la configuration.

Architecture locale

Aucun serveur central n'est nécessaire : vous ouvrez simplement le fichier HTML dans votre navigateur. Le navigateur contacte ensuite directement chaque ESP32-CAM sur le réseau local, par exemple http://192.168.1.2.

Protocoles réseau

Les échanges se font en HTTP sur le réseau local. Les flux et commandes utilisent des URLs internes exposees par le firmware ESP32-CAM. Il n'y a pas de HTTPS ici, ce qui est courant sur ESP32 mais signifie que le trafic n'est pas chiffré sur le Wi-Fi.

Routes ESP32-CAM

  • /stream sert au flux vidéo continu.
  • /capture sert à demander une image fixe.
  • /led/on et /led/off servent aux commandes LED.
  • / sert au test de disponibilité et affiche souvent l'interface interne de l'ESP32.

Flux ESP32-CAM

Chaque carte affiche http://IP/stream dans une iframe. Ce choix est volontaire : votre firmware diffuse correctement le flux dans une iframe, alors qu'un essai avec une balise image directe n'affichait pas d'image malgré le statut en ligne.

La vignette est centrée dans un cadre noir au format 4:3. L'iframe part d'une base 320×240 puis Surveillant la met à l'échelle selon la taille disponible, afin d'éviter les barres blanches du rendu navigateur.

Configuration

Le menu presente une camera vide par defaut, puis permet d'ajouter autant de cameras que necessaire avec une couleur, une IP et un libelle. Une camera n'apparait dans la grille que si son IP est renseignée. La rotation, le miroir horizontal, le thème, les libellés, le chemin du flux, le chemin de capture, la fréquence de rafraîchissement, le délai entre caméras, l'agencement, le format de date et le choix d'affichage du tutoriel sont sauvegardés localement dans localStorage.

Horodatage

L'horloge du haut est formatée en JavaScript avec toLocaleString("fr-FR"). Le menu permet de choisir entre un format court numérique et un format long avec le jour de la semaine et le mois en toutes lettres. Les noms de fichiers de capture gardent volontairement un format technique YYYY-MM-DD_HH-MM-SS, plus fiable pour le tri et compatible avec les systèmes de fichiers.

Agencement compact des cartes

Les cartes caméra ont été compactées pour donner plus de hauteur au flux : le nom, l'IP et l'état occupent un en-tête réduit, les 6 commandes sont superposées au flux dans deux rails latéraux, et les messages de capture ou d'état apparaissent en petit overlay en bas de l'image. En mode Surveillance, ces contrôles et messages sont masqués pour ne garder que les flux sous la barre du haut.

Rafraîchissement décalé

Le bouton global ↻, la mise à jour automatique, les tests de statut et le démarrage initial ne sollicitent pas toutes les caméras en même temps. Surveillant utilise une petite file d'attente JavaScript : une caméra est traitée, puis la suivante après le délai choisi dans Décalage maj. Cela limite les pics de requêtes HTTP et réduit les risques de lag côté ESP32-CAM ou Wi-Fi.

Captures

Le bouton capture appelle http://IP/capture, convertit l'image en PNG puis l'enregistre dans le dossier choisi ou la télécharge directement. Le navigateur ne donne pas le chemin complet du dossier, seulement son nom et l'autorisation d'écriture. Si l'ESP32-CAM bloque la lecture directe par CORS, Surveillant essaie automatiquement le proxy local capture-proxy.js sur 127.0.0.1:8787.

Affichage et transformations

La rotation, le miroir horizontal et le zoom agrandi sont appliqués côté navigateur avec des transformations CSS. Cela ne modifie pas le flux réel envoyé par l'ESP32 : seule l'image affichée dans Surveillant est transformée.

Sécurité

Cette page ne protège pas les caméras : elle pilote des URLs HTTP locales. Toute personne connectée au même réseau peut potentiellement appeler les mêmes URLs directement. La vraie sécurité repose sur le Wi-Fi, l'absence de redirection de port, un réseau invité isolé et, idéalement, un réseau IoT séparé ou un accès VPN pour l'extérieur.

Bienvenue

Bienvenue, voici un tutoriel explicatif afin de vous guider dans l'utilisation de Surveillant.

Les prochaines étapes vous accompagnent depuis la préparation de l'ESP32-CAM jusqu'à l'ajout de votre première caméra dans le menu.

1. Installer l'environnement Arduino

Installez l'IDE Arduino, puis ajoutez la prise en charge des cartes ESP32 par Espressif depuis le gestionnaire de cartes.

Télécharger l'IDE Arduino depuis le site officiel

  • Ouvrez l'IDE Arduino.
  • Mettez à jour l'I.D.E si besoin.

2. Ajouter l'URL Espressif

Dans les préférences de l'IDE Arduino, ajoutez l'URL officielle du gestionnaire de cartes ESP32 Espressif dans le champ des URLs additionnelles.

https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

  • Ouvrez les préférences de l'IDE Arduino.
  • Repérez le champ des URLs additionnelles de gestionnaire de cartes.
  • Collez l'URL Espressif, puis validez.

3. Préparer le sketch ESP32-CAM

Ouvrez le fichier surveillant_esp32cam.ino, puis renseignez les informations propres à votre réseau.

  • Remplacez ssid par le nom de votre réseau Wi-Fi.
  • Remplacez password par le mot de passe Wi-Fi.
  • Choisissez le dernier nombre de l'IP avec local_IP[3].

4. Brancher l'ESP32-CAM à l'ordinateur

Branchez l'ESP32-CAM à votre ordinateur avec l'adaptateur ou le programmateur adapté à votre module.

  • Utilisez un câble USB capable de transporter des données.
  • Vérifiez que le module est correctement alimenté.
  • Si votre carte le demande, placez-la en mode téléversement avant d'envoyer le sketch.

5. Attribuer une IP à la caméra

La ligne local_IP[3] = 10; donne le dernier nombre de l'adresse IP. Sur un réseau 192.168.1.x, cela donne 192.168.1.10.

  • Utilisez un numéro différent pour chaque ESP32-CAM.
  • Réservez idéalement cette IP dans votre box pour éviter les conflits.
  • Notez l'IP choisie : vous devrez la reporter dans Surveillant.

6. Sélectionner la carte

Dans l'IDE Arduino, sélectionnez le type de carte correspondant à votre ESP32-CAM.

  • Ouvrez le menu de sélection des cartes.
  • Choisissez une carte compatible avec votre module.
  • Pour beaucoup de modules ESP32-CAM classiques, le choix AI Thinker ESP32-CAM convient.

7. Sélectionner le port

Sélectionnez le port série utilisé par l'ESP32-CAM ou par son programmateur USB.

  • Ouvrez le menu des ports.
  • Choisissez le port qui apparaît quand l'ESP32-CAM est branchée.
  • Si aucun port n'apparaît, vérifiez le câble USB, le pilote série et le mode de téléversement.

8. Téléverser et redémarrer

Téléversez le sketch dans l'ESP32-CAM, puis redémarrez le module. Quand l'ESP32-CAM est connectée au Wi-Fi, elle expose les routes utilisées par Surveillant.

  • /stream pour le flux vidéo.
  • /capture pour les captures si le firmware le propose.
  • /led/on et /led/off pour la LED.

9. Ajouter la caméra dans Surveillant

Ouvrez le menu de Surveillant, renseignez l'IP de la caméra, puis ajoutez si besoin une couleur et un libellé pour l'identifier facilement.

  • Entrez l'IP choisie, par exemple 192.168.1.10.
  • Ajoutez un libellé utile, comme une pièce ou une zone.
  • Enregistrez, puis vérifiez que le flux apparaît dans la grille.

Fin du tutoriel

Reportez-vous à la section aide si besoin, bonne utilisation !
